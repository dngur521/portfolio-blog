- [완주하지 못한 선수](https://school.programmers.co.kr/learn/courses/30/lessons/42576)

```
def solution(participant, completion):

    count = {}

    # count 딕셔너리에 이름, 숫자(선수 갯수) 삽입
    for name in participant:
        print(name)
        if name in count:
            count[name] += 1
        else:
            count[name] = 1

    # count 딕셔너리에 완주한 선수가 있으면 선수 갯수에서 1을 뺌
    for name in completion:
        count[name] -= 1

    # 그렇게 해서 1이 남은 선수의 이름을 반환
    for name in participant:
        if count[name] == 1:
            return name

```
